===============================================================================
ARCHITECTURE
===============================================================================

Frontend (React/TypeScript)
    ↓
Backend (Node.js/Express)
    ↓
ML Service (Python/FastAPI)
    ↓
SHAP Explainer (Python)
    ↓
Trained Model (scikit-learn/etc)

Data Flow:
  1. User requests explanation via frontend
  2. Frontend calls backend API with JWT token
  3. Backend proxies request to ML service
  4. ML service loads model and creates SHAP explainer
  5. SHAP calculates feature contributions
  6. Visualizations generated (waterfall, force, text)
  7. Results returned through chain to frontend
  8. Frontend renders interactive visualizations

PERFORMANCE
===============================================================================

SHAP Calculation Speed:
  • TreeExplainer (Random Forest): ⚡ Fast (<1 sec)
  • LinearExplainer: ⚡⚡ Very Fast (<0.1 sec)

Optimization:

Resource Usage:
  • Memory: ~100-500 MB per explainer
  • CPU: High during calculation (10-30 sec)
  • Disk: ~50 KB per exported report
