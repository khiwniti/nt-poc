# T222: Monitoring and Observability Implementation

## Overview
Added comprehensive monitoring and observability infrastructure with Sentry error tracking, Winston logging, and Prometheus metrics.

## Components Implemented

### 1. Error Tracking (Sentry)
- **Configuration**: `src/config/sentry.ts`
- **Features**:
  - Automatic error capture
  - Performance monitoring
  - Profiling integration
  - Environment-based configuration
  - Request/error context tracking

### 2. Logging (Winston)
- **Configuration**: `src/config/logger.ts`
- **Features**:
  - Multiple log levels (debug, info, warn, error)
  - Console and file transports
  - JSON format for production
  - Colored console output for development
  - Log rotation (10MB max, 5-10 files)
  - Structured logging with metadata

### 3. Metrics (Prometheus)
- **Configuration**: `src/config/metrics.ts`
- **Metrics Collected**:
  - **HTTP Metrics**:
    - Request duration histogram
    - Request count by method/route/status
  - **Application Errors**:
    - Error count by type and route
  - **Prediction Metrics**:
    - Prediction duration by model type
    - Prediction count by model/status
  - **Alert Metrics**:
    - Alerts generated by severity/type
  - **Database Metrics**:
    - Query duration by operation/table
  - **Job Metrics**:
    - Job execution duration
    - Job execution count by status
  - **System Metrics**:
    - CPU, memory, event loop (default metrics)

### 4. Middleware
- **Logging Middleware** (`src/middleware/logging.ts`):
  - Logs all HTTP requests and responses
  - Includes duration, status, method, URL
- **Metrics Middleware** (`src/middleware/metrics.ts`):
  - Records HTTP metrics automatically
- **Error Handler** (`src/middleware/errorHandler.ts`):
  - Centralized error handling
  - Sentry integration
  - Error metrics tracking

### 5. Monitoring Utilities
- **File**: `src/utils/monitoring.ts`
- **Functions**:
  - `trackPrediction()` - Track ML prediction performance
  - `trackDbQuery()` - Track database query performance
  - `trackJobExecution()` - Track scheduled job execution
  - `trackAlert()` - Track alert generation
  - `setErrorContext()` - Set custom context for errors
  - `setUserContext()` - Set user context for errors
  - `captureMessage()` - Capture custom messages

### 6. Monitoring Endpoints
- **Route**: `src/routes/monitoring.ts`
- **Endpoints**:
  - `GET /api/v1/health` - Health check with database connectivity
  - `GET /api/v1/metrics` - Prometheus metrics endpoint

### 7. Alert Thresholds
- **Configuration**: `src/config/alertThresholds.ts`
- **Thresholds Defined**:
  - HTTP error rates (warning: 5%, critical: 10%)
  - Response times (warning: 2s, critical: 5s)
  - Prediction error rates (warning: 2%, critical: 5%)
  - Database query times (warning: 1s, critical: 2s)
  - System resources (memory: 80%/90%, CPU: 70%/85%)
  - Job execution times
  - Alert generation rates

## Integration Points

### In Application Code
The monitoring is automatically integrated into:
- All HTTP requests (via middleware)
- Error handling (via error handler)
- Application startup (Sentry initialization)

### For Scheduled Jobs
Update job services to use `trackJobExecution()`:
```typescript
import { trackJobExecution } from '../utils/monitoring.js';

export async function runJob() {
  return trackJobExecution('job-name', async () => {
    // Job logic
  });
}
```

### For Database Operations
Use `trackDbQuery()` for critical queries:
```typescript
import { trackDbQuery } from '../utils/monitoring.js';

const results = await trackDbQuery('select', 'facilities', async () => {
  return db('facilities').select('*');
});
```

## Alert Monitoring

### Sentry Alerts
Configure in Sentry dashboard:
- Error rate thresholds
- Performance degradation
- New error types

### Prometheus Alerts (Grafana/AlertManager)
Example alert rules:
```yaml
groups:
  - name: battery_management
    rules:
      - alert: HighErrorRate
        expr: rate(http_requests_total{status_code=~"5.."}[5m]) > 0.05
        annotations:
          summary: "High error rate detected"
      
      - alert: SlowPredictions
        expr: histogram_quantile(0.95, prediction_duration_seconds) > 5
        annotations:
          summary: "Predictions are slow"
```

## Log Files

Logs are stored in `logs/` directory:
- `error.log` - Error level logs only (max 10MB, 5 files)
- `combined.log` - All logs (max 10MB, 10 files)
