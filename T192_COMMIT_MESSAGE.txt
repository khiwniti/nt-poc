feat(T192): Integrate Mapbox GL JS for facility maps

Replace Leaflet with Mapbox GL JS for interactive facility mapping with
health status indicators and clustering support.

Features:
- Mapbox GL JS integration with light theme
- Health-based marker colors (green/yellow/red)
- Automatic clustering for dense areas (radius: 50px)
- Interactive popups with facility details
- Comprehensive map controls (navigation, fullscreen, geolocate, scale)
- Mobile-optimized touch controls
- Environment-based API key configuration

Health Status Indicators:
- Healthy (green): SoH ≥ 80%, alerts ≤ 2, active status
- Warning (amber): SoH 60-80%, alerts 3-5, maintenance
- Critical (red): SoH < 60%, alerts > 5, inactive/offline

Map Controls:
- Navigation control (zoom, compass)
- Fullscreen toggle
- Geolocate (user location)
- Scale indicator (desktop only)
- Clustering with click-to-expand
