# Documentation Structure

This directory contains all project documentation organized by category.

## 📁 Directory Structure

### `/development/`
Development processes, testing guidelines, and quality standards:
- `CODE_REVIEW_CHECKLIST.md` - Code review guidelines
- `INTEGRATION_TESTS_QUICK_REF.md` - Integration testing reference
- `REAL_DATA_QUICK_START.md` - Working with real data
- `TESTING_STRATEGY.md` - Overall testing approach
- `TEST_INFRASTRUCTURE_GUIDE.md` - Test infrastructure setup
- `TEST_WRITING_GUIDELINES.md` - How to write tests

### `/features/`
Feature-specific implementation documentation:
- `RUL_PREDICTION_IMPLEMENTATION.md` - Remaining Useful Life prediction
- `SENSOR_DATA_INTEGRATION.md` - Sensor data integration
- `VR_README.md` - VR/3D visualization features

### `/infrastructure/`
Infrastructure, deployment, and operations:
- `KUBERNETES_DEPLOYMENT.md` - Kubernetes deployment guide
- `KUBERNETES_QUICKSTART.md` - Quick K8s setup
- `DOCKER_DEVELOPMENT.md` - Docker development environment

### `/archive/`
Historical documentation, completed tasks, and deprecated files:
- `tasks/` - Task-specific implementation documents (T###_*.md)
- `old-docs/` - Superseded documentation
- `scripts/` - Deprecated scripts
- `logs/` - Historical logs
