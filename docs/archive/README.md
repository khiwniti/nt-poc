# Archive Directory

This directory contains historical documentation and temporary files that are not part of the active codebase but are preserved for reference.

## Structure

- **tasks/** - Task-specific implementation documents (T###_*.md files)
  - Implementation summaries
  - Acceptance checklists
  - Quick reference guides
  - File manifests

- **old-docs/** - Superseded or duplicate documentation
  - Migration guides
  - Deployment summaries
  - Status reports
  - Backup configurations

- **scripts/** - Deprecated or one-time scripts
  - Cleanup utilities
  - Migration scripts
  - Production deployment helpers

- **logs/** - Historical build and deployment logs
