# Quick Start Guide - Railway Deployment

**Complete production deployment in 15 minutes!**

## 🎯 Prerequisites

- Railway account (https://railway.app)
- Google Gemini API key (https://ai.google.dev/)

## 🚀 Deployment Steps

### 1. Create Railway Project (2 min)

1. Go to https://railway.app
2. Click **"New Project"**
3. Select **"Deploy PostgreSQL"**
4. Name it: `nt-poc-database`

### 2. Enable TimescaleDB (1 min)

```bash
# In Railway PostgreSQL service shell
psql $DATABASE_URL -c "CREATE EXTENSION IF NOT EXISTS timescaledb;"
```

### 3. Deploy Backend Service (3 min)

**Create Service:**
1. **"New Service"** → **"GitHub Repo"**
2. Select your repository
3. Set **Root Directory**: `services/backend`
4. Railway auto-detects `railway.json`

**Set Environment Variables:**
```bash
NODE_ENV=production
PORT=3000

# Database (use Railway references)
DB_HOST=${{Postgres.PGHOST}}
DB_PORT=${{Postgres.PGPORT}}
DB_NAME=${{Postgres.PGDATABASE}}
DB_USER=${{Postgres.PGUSER}}
DB_PASSWORD=${{Postgres.PGPASSWORD}}
DB_SSL=true

# JWT (generate: openssl rand -base64 32)
JWT_SECRET=YOUR_GENERATED_SECRET_HERE

# Service URLs (Railway references)
MLOPS_SERVICE_URL=https://${{MLOps.RAILWAY_PRIVATE_DOMAIN}}
SIMULATOR_URL=https://${{Simulator.RAILWAY_PRIVATE_DOMAIN}}

# Sensor Ingestion
SENSOR_INGESTION_ENABLED=true
SENSOR_INGESTION_INTERVAL=10000
```

**✅ Verify:** Check logs for `✅ Database migrations completed successfully`

### 4. Deploy MLOps Service (2 min)

**Create Service:**
1. **"New Service"** → **"GitHub Repo"**
2. Set **Root Directory**: `services/mlops`
3. Railway auto-detects `railway.json`

**Set Environment Variables:**
```bash
ENVIRONMENT=production
PORT=8001
LOG_LEVEL=INFO
```

**✅ Verify:** Health check at `https://your-mlops-url.railway.app/health`

### 5. Deploy Simulator Service (2 min)

**Create Service:**
1. **"New Service"** → **"GitHub Repo"**
2. Set **Root Directory**: `services/simulator`
3. Railway auto-detects `railway.json`

**Set Environment Variables:**
```bash
ENVIRONMENT=production
PORT=8002
SENSOR_BACKEND=simulator
LOG_LEVEL=INFO
```

**✅ Verify:** Health check at `https://your-simulator-url.railway.app/api/health`

### 6. Deploy Frontend Service (3 min)

**Create Service:**
1. **"New Service"** → **"GitHub Repo"**
2. Set **Root Directory**: `services/frontend`
3. Railway auto-detects `railway.json`

**Set Environment Variables:**
```bash
NODE_ENV=production

# API URLs (Railway references)
VITE_API_BASE_URL=https://${{Backend.RAILWAY_PUBLIC_DOMAIN}}

# Gemini API Key (GET THIS FROM https://ai.google.dev/)
VITE_GEMINI_API_KEY=YOUR_GEMINI_KEY_HERE

# App Config
VITE_APP_NAME=NT Battery Management System
VITE_ENVIRONMENT=production
VITE_ENABLE_DEBUG_MODE=false
```

**✅ Verify:** Open frontend URL in browser

### 7. Verify Complete Integration (2 min)

**Test Checklist:**

1. **Backend Health:**
   ```bash
   curl https://your-backend.railway.app/api/v1/health
   ```
   Should return: `{ "status": "ok", "database": "connected" }`

2. **Data Flow:**
   - Check backend logs for: `sensor_ingestion_run_completed`
   - Wait 60 minutes, check for: `scheduled_prediction_job_run_completed`

3. **Frontend:**
   - Load frontend URL in browser
   - Should see dashboard with battery data

4. **RAG Chatbot:**
   - Click chat widget (bottom right)
   - Ask: "What's the current status?"
   - Should get system summary with real data

## 🔑 Critical Environment Variables

### Must Have (Services won't work without these)

| Service | Variable | How to Get |
|---------|----------|------------|
| Backend | `JWT_SECRET` | `openssl rand -base64 32` |
| Frontend | `VITE_GEMINI_API_KEY` | https://ai.google.dev/ |
| All | Railway DB references | Auto-generated by Railway |

### Optional (Enhanced features)

- `SENDGRID_API_KEY` - Email notifications
- `VITE_MAPBOX_API_KEY` - Map features
- `WEATHER_API_KEY` - Weather data integration

## 🐛 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Migrations don't run | Check backend logs, verify DB connection |
| Services can't communicate | Verify Railway domain references in env vars |
| Chatbot not working | Check `VITE_GEMINI_API_KEY` is set |
| No sensor data | Verify `SIMULATOR_URL` and simulator health |
