feat(geospatial): Add map export functionality (T204/US6)

Implements comprehensive map export functionality with support for PNG,
GeoJSON, and KML formats, including filter integration and rich metadata.

Features:
- Export map view as high-quality PNG image (2x scale)
- Export facilities as GeoJSON (RFC 7946 compliant)
- Export facilities as KML (Google Earth compatible)
- Include applied filters in export metadata
- Rich metadata (date, count, bounds, filters)
- Automatic download handling with cleanup

UI/UX:
- Export controls dropdown in top-right corner
- Three clearly labeled format options
- Disabled state when no facilities present
- Keyboard accessible (Tab, Enter, Space, Arrows)
- Screen reader support with ARIA attributes
- Live region announcements for export status
- High contrast mode support
