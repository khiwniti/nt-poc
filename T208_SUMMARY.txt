DOCUMENTATION HIGHLIGHTS
-------------------------
API Endpoints:
- GET /api/facilities (list with coordinates)
- GET /api/facilities/:id (single facility location)
- GET /api/facilities/nearby (find nearest)
- GET /api/facilities/distance (calculate distance)
- POST /api/geocoding/forward (address → coordinates)
- POST /api/geocoding/reverse (coordinates → address)

Coordinate Formats:
- WGS84 (EPSG:4326) - Standard format
- Latitude: -90 to +90, Longitude: -180 to +180
- Recommended precision: 4-6 decimal places
- Alternative formats: GeoJSON, DMS, WKT

Distance Calculations:
- Haversine formula (fast, accurate)
- Vincenty formula (high precision, 0.5mm accuracy)
- PostgreSQL/PostGIS implementation
- Support for km, miles, meters

Geocoding Integration:
- Google Maps API (most accurate)
- OpenStreetMap Nominatim (free alternative)
- Caching strategy (24h TTL)
- Rate limiting implementation

Map Embedding:
- Google Maps React components
- Leaflet (open source alternative)
- Marker clustering for performance
- Static map generation for emails

Performance Optimization:
- Spatial indexing (GIST) - 10-100x speedup
- Bounding box pre-filtering
- Multi-level caching (geocoding, distances, coordinates)
- Batch distance calculations
- Target latencies documented
